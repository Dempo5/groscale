GroScales

GroScales is my personal SaaS project where I am building a full CRM and automation system for insurance agents. The whole point is simple: get rid of the messy lead workflow most agents deal with and replace it with something clean, fast, automated and actually useful. I am building everything myself while studying Computer Science at UCF and working in the insurance industry, so GroScales reflects real problems I experienced every day.

This project is still growing, but the goal is to create a tool that lets agents stop wasting time and start booking more appointments with less effort.



Features

Lead Management
	•	CSV importing with auto mapping
	•	Tags for fast sorting
	•	Status pipeline for tracking leads
	•	Searching and filtering

SMS Messaging
	•	Two way texting using Twilio or Telnyx
	•	Message templates
	•	Bulk text support
	•	Delivery and read status

Automation
	•	Auto text sequences for new leads
	•	AI generated responses for common questions
	•	Drip message flows
	•	Event triggers that fire based on status changes

AI Copilot
	•	Helps write texts
	•	Gives suggested next actions
	•	Summarizes long conversations
	•	Helps build scripts and follow up messages

Dashboard and Analytics
	•	Daily message activity
	•	Lead conversion stats
	•	Reminder system
	•	Agent productivity tracking

Authentication and Security
	•	Passwordless login
	•	Prisma ORM for clean database structure
	•	Role based access levels
	•	Secure sessions



Tech Stack

Frontend
	•	React
	•	Next.js
	•	TypeScript
	•	TailwindCSS and ShadCN UI
	•	React Query

Backend
	•	Node and Express
	•	Prisma
	•	PostgreSQL
	•	Twilio and Telnyx
	•	OpenAI API

Infrastructure
	•	Vercel for frontend
	•	Render for backend
	•	Railway for Postgres
	•	Upstash for caching and rate limits
